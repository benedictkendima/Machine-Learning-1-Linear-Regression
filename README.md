# Machine Learning 1 - Linear Regression

This project introduces Linear Regression, a supervised machine learning algorithm used to predict continuous numerical values.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

### Activities
- Data preparation
- Training and testing datasets
- Building a Linear Regression model
- Making predictions
- Evaluating model performance

### Objective
To understand how Linear Regression works and how it can be used for numerical predictions.
